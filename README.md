# 🏦 Bank Loan Analysis Dashboard | Excel • MS SQL Server • Power BI

## 📌 Project Overview

The **Bank Loan Analysis Project** focuses on analysing a bank's lending activities, loan portfolio performance, borrower profiles, and repayment trends through an interactive Power BI dashboard.

The project follows an end-to-end data analytics workflow, starting with data validation in Microsoft Excel, integrating data with MS SQL Server, and connecting the database to Power BI to develop dynamic dashboards that transform raw loan data into actionable business insights.

The dashboard helps stakeholders monitor lending performance, evaluate loan quality, identify trends, and make data-driven decisions to support effective loan portfolio management.

## 🎯 Business Objectives

- Monitor overall loan applications, funded amounts, and repayments.
- Track Month-to-Date (MTD) performance and Month-over-Month (MoM) changes.
- Evaluate good loans versus bad loans based on loan status.
- Analyse lending trends across states, loan purposes, loan terms, and borrower employment history.
- Understand borrower financial profiles using interest rates and Debt-to-Income (DTI) ratios.
- Provide a consolidated view of loan portfolio performance through interactive dashboards.

## 📊 Dashboard Modules

### 1. Summary Dashboard

Provides a high-level overview of the bank's lending performance through key performance indicators (KPIs).

**Key Metrics:**
- Total Loan Applications
- Month-to-Date (MTD) Loan Applications
- Month-over-Month (MoM) Application Growth
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average Debt-to-Income (DTI) Ratio

**Good Loan vs. Bad Loan Analysis**

Good loans include loans with a status of **Fully Paid** or **Current**, while bad loans are identified by the **Charged Off** status.

The dashboard evaluates:
- Good Loan Application Percentage
- Good Loan Applications
- Good Loan Funded Amount
- Good Loan Amount Received
- Bad Loan Application Percentage
- Bad Loan Applications
- Bad Loan Funded Amount
- Bad Loan Amount Received

A loan status grid provides a detailed comparison of applications, funding, repayments, interest rates, and DTI metrics across different loan categories.

### 2. Overview Dashboard

Provides visual insights into lending patterns and borrower characteristics using multiple chart types.

| Visualization | Business Insight |
|---|---|
| Monthly Trend – Line Chart | Tracks loan applications, funded amounts, and repayments over time |
| State-wise Filled Map | Identifies regional lending patterns |
| Loan Term – Donut Chart | Compares loans across different repayment terms |
| Employee Length – Bar Chart | Analyses lending activity by employment tenure |
| Loan Purpose – Bar Chart | Highlights the most common reasons for borrowing |
| Home Ownership – Treemap | Examines loan distribution by home ownership status |

These visualizations help identify lending trends, regional variations, and borrower segments that contribute to the bank's loan portfolio.

### 3. Details Dashboard

Provides a consolidated view of loan-level information and borrower profiles, enabling users to explore individual records and investigate portfolio performance in greater detail.

The dashboard supports detailed analysis of loan status, loan amounts, repayments, interest rates, DTI ratios, and other available borrower attributes.

## 🔄 Project Workflow

1. **Data Validation – Excel:** Checked the source dataset for data quality and consistency.
2. **Database Integration – MS SQL Server:** Imported and organized the validated data for analysis.
3. **Data Connection – Power BI:** Connected Power BI to the SQL Server database.
4. **Data Modelling & Calculations:** Prepared analytical measures for KPIs, MTD performance, and MoM comparisons.
5. **Dashboard Development:** Created three interactive dashboard pages: Summary, Overview, and Details.
6. **Business Analysis:** Evaluated lending trends, repayment performance, loan quality, and borrower characteristics.

## 💡 Key Business Value

- Assess portfolio quality through good loan and bad loan classifications.
- Identify borrower segments and regions with significant lending activity.
- Evaluate interest rates and borrower debt-to-income ratios.
